# Отчетность в Allure

Данный проект является доработкой домашнего задания №7 «PageObject».
В рамках задания реализована отчетность с использованием Allure Framework,
а также выполнено документирование кода.

---

## Работа с проектом

Проект написан на языке Python с использованием:
- Pytest — для запуска автотестов;
- Selenium WebDriver — для взаимодействия с браузером;
- Allure — для формирования тестовой отчетности.

Все тесты и PageObject-классы находятся в папке lesson_10.

---

## Документирование кода

- Все PageObject-классы задокументированы с помощью docstring.
- Каждый метод содержит:
  - описание назначения;
  - типы входных параметров (кроме self);
  - тип возвращаемого значения.
